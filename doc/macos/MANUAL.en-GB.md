## Status

The PYMEHackers Control Center core is **not available for macOS**. There is nothing to install: the one-line installers of the project only work on Debian.

## Using modules on macOS

Modules that support macOS work on their own, without the core. Install each one from [PHCC-modules](https://github.com/pymehackers/PHCC-modules) following the documentation of that module, which explains its installer, its service and how to configure it.
