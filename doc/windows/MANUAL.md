## Status

The PYMEHackers Control Center core is **not available for Windows**. There is nothing to install: the one-line installers of the project only work on Debian.

## Using modules on Windows

Modules that support Windows work on their own, without the core. Install each one from [PHCC-modules](https://github.com/pymehackers/PHCC-modules) following the documentation of that module, which explains its installer, its service and how to configure it.
